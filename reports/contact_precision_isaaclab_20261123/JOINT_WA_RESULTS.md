# JOINT_WA_RESULTS — 가중치·activation 공동 양자화 (Stage 5, 조건부)

작성 2026-11-24.

## 0. 진행 범위

- 명세상 Stage 5(접촉 조건 dynamic joint W/A)는 Stage 2–3에서 접촉 의존 정밀도 요구가 확인될 때만 진행한다.
- Stage 2–3 판정이 모두 부정이었다(`CONTACT_SENSITIVITY.md`, `PRECISION_DEMAND.md`). 그래서 이번 캠페인에서 **접촉 조건 W/A 폐루프와 전체 W/A 오프라인 sweep은 진행하지 않았다**(NOTES 23:17).
- 아래 내용은 셋으로 나뉜다.
  1. 이번 정책에서 측정한 부분 결과
  2. 같은 날 앞선 캠페인(다른 정책)의 측정 결과 인용
  3. 저장 비용의 분석적 추정

## 1. 이번 정책(GR00T N1.5 tactile, 작업 27)의 부분 측정

설정: DiT linear 전체, 가중치 W4(group 128 비대칭), activation A4(tile 32).
- 시험 시연 0–1의 49 관측만 측정했다. Stage 3 `WA|dit|rand_s|0.0`이 멈춘 지점까지다.
- 같은 관측에서 비교했다.

| 설정(DiT linear 전체) | 정규화 오차(× noise, 기하평균) |
|---|---|
| A8(가중치 BF16) | 0.069 |
| A4(가중치 BF16) | 2.11 |
| W4 + A4 | **2.64** |

- DiT에서 W4를 더하면 A4 단독보다 오차가 25% 커진다.
- 접촉/비접촉 비교는 표본(49)이 작고, 관측이 시연 2개에 몰려 있어 하지 않았다.

이번 정책과 모델(N1.6 대 N1.5)도 환경(LIBERO 대 Bench2Dex)도 다르다. 일반 경향으로만 참고한다.

| 질문 | 측정 결과 |

| Selective W/A(channel 쌍 보호) | 중요 channel 3%의 activation과 가중치 열 W[:,S]를 함께 8비트로 두면, 오프라인 오차가 균일 W4A4의 0.27배였다. 폐루프에서는 W4A4 손실을 회복했지만(+6.7%p [+1.3, +12.0]) 무작위 3%와 구분되지 않았다(+2.7%p [−3.3, +8.7]) |

| 폐루프 W8A8 | Goal −0.7%p [−4.7, +3.3], Long −1.7%p [−5.7, +2.3]. 손실이 검출되지 않았다 |

## 3. 이번 정책에서의 static과 dynamic(activation, 측정; `PRECISION_DEMAND.md`)

ε = 0.25에서 DiT linear에 필요한 INT8 channel 비율이다.

| 선택 | 필요 비율 |
|---|---|
| 동적 \|x\|·\|W\| | 35% |
| 정적 \|x\|·\|W\| | 50% |
| 무작위 | 75% |

동적 선택은 activation에서 15%p를 아낀다. 하지만 접촉 상태와는 무관하다. 따라서 "접촉에 따라 동적으로"가 아니라 "호출마다 activation 크기로" 고르는 것이고, 이는 기존 LLM outlier 처리와 같은 신호다.

## 4. 저장·metadata 비용(분석적 추정, 이번 정책 DiT 550M 파라미터 기준)

| 방식 | 가중치 저장 | 추가 metadata | 비고 |
|---|---|---|---|
| BF16 | 1.10 GB | — | 기준 |
| 균일 W8 | 0.55 GB | 출력 channel scale ≈ 1 MB | |
| 균일 W4(g128) | 0.28 GB | group scale·zero ≈ 17 MB | |
| 정적 W[:,S] 쌍 보호 r = 35% | 0.65 × 0.28 + 0.35 × 0.55 ≈ **0.37 GB** | 층마다 보호 channel index(입력 channel의 35%를 16비트로) ≈ 0.1 MB | 선택이 고정이라 한 가지 형식만 저장 |
| 동적 W[:,S](호출마다 S가 바뀜) | 어떤 열이든 고정밀이 될 수 있으므로 W8 전체 + W4 사본 ≈ **0.83 GB**. W8에서 W4를 실시간으로 만들면 0.55 GB + 변환 연산 | 호출마다 index 목록 | 정적 대비 2.2배. W4 대비 3배 |
| 접촉 조건 dynamic(가설) | 동적과 같다 | 접촉 판정 신호 | 이 정책에서는 접촉이 S를 바꾸지 않으므로(겹침 0.75–0.78) 정적과 같은 S를 두 벌 저장하는 셈 |

DiT는 flow step 4번마다 가중치를 다시 읽는다. 그래서 호출당 가중치 읽기는 BF16 4.4 GB, W4 1.1 GB, 정적 r = 35% 1.5 GB다(추정). RTX 3090 대역폭 936 GB/s로 나누면 각각 4.7, 1.2, 1.6 ms다. 실측 DiT 시간은 25 ms다(`HARDWARE_ANALYSIS.md`). 즉 DiT는 대역폭보다 kernel 실행과 연산이 지배한다(추정).

## 5. 결론

- 이 정책에서 접촉 조건 joint W/A로 이득을 볼 근거는 없다. 접촉이 필요한 정밀도도, 중요 channel 위치도 바꾸지 않는다.
- 같은 정확도를 더 적은 비용으로 얻는 확인된 방법은 다음 두 가지다.
  - 균일 W8A8: 앞선 캠페인의 실측 1.25배, 폐루프 손실 미검출.
  - 위치별 정적 혼합 정밀도: action head 출력 경로만 고정밀(추정).
- 둘 다 기존 기법이다.
